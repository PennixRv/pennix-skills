# 解决方案设计与收敛阶段

实际接口权衡、可由原型验证的具体未知、已有材料成文及批准前输出复核，可采用宿主已声明的相关方法。方法明确就直接使用，组合不清时按需使用可用总路由；只完成当前所需产物后返回，方法不替代整体方案接受和实施授权。

当 `current_phase_id` 为 `solution_design_and_convergence` 时使用。阅读本 Skill 同目录的 `workflow.md`，核对当前有效的需求基线和决策空间构造与归并阶段结果或跳过记录。

本阶段锁定当前路线所依据的决定和方案，不代表实施已获授权。需用户决定时，使用 `pennix-decision-grill` 同步询问并留在解决方案设计与收敛阶段；实施路线须形成 `implementation_contract`，再单独取得实施批准后才能进入任务实施与测试验证阶段。触发 prior-art review 的方案须在阶段结果接受前完成该审查。
