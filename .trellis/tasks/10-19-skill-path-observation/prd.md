# 收敛 Skill 路径加载与行为采集

## 目标（Goal）

落实根任务 skill-path-resolution-recurrence 已批准方案中的 routing 原段落、评估路径事件与专项回归；不增加 Hook、目录迁移或新安装体系。

## 需求（Requirements）

- 修改目标仅为 `evaluations/run_codex_cases.py`、现有评估测试、routing 的“Skill 身份与路径”段及对应合同测试；不修改其他 Skill 或安装副本。
- 按事件保留具体路径、逻辑名、工具及读取结果；失败、成功、未知分开，首次错后成功仍保留失败。组合命令不能可靠归因时保持未知，不构建通用 Shell 解释器。
- 路径取值遵守本轮宿主声明，根别名仅展开根目录，保留集合和项目层级；相对引用从实际 Skill 文件目录解析。移除该段中文逐句冻结，使用行为回归和语义审查。
- 本工作项是根任务 `skill-path-resolution-recurrence` revision 1 已展示方案中明确列出的同一组件目标。用户随后明确批准“按照方案约定的完整流程完整推进到停止点完成”，该批准覆盖此处列明的来源修正、验证与提交推送；不借用 10-17 旧任务批准。

## 验收标准（Acceptance Criteria）

- [ ] 新增回归在旧采集上失败，修正后通过，覆盖主集合、extra、项目、别名展开后的实际路径、相对引用、首次失败后恢复和未知形态。
- [ ] 路径提及、MCP 参数或命令成功不能单独成为成功读取证据；摘要不保存原始命令、消息、正文或秘密。
- [ ] 相关既有测试、集合原生验证和差异检查通过，变更提交推送后交由根任务固定来源并传播；真实宿主验收不以静态测试代替。

## 备注（Notes）

- 正常停止于本组件来源修正、回归、提交推送和验收记录完成；部署与当前宿主行为结论由根任务继续核验。失败保留结果，超出上述目标时停止并返回根任务规划，不新增 Hook、兼容路径或采集系统。
