# Design

The source owner is this repository on main. The full cross-owner contract is the root coordination task `.trellis/tasks/10-21-code-search-routing-convergence/design.md` in the parent checkout. This local task implements that same displayed and approved plan, not a new proposal.

Keep the complete source/transport decision table in workflow-routing. Context Mode owns execution, aggregation and acquired-text search; CodeGraph owns indexed symbols/relations; Windsurf owns bounded semantic candidate discovery. An effective symbol/module anchor selects CodeGraph, a literal/path selects exact text in Context Mode, and clear semantic location without a code anchor can go directly to Windsurf within existing external limits. Candidates require current-source validation.

Loading external AGENTS/SKILL instructions and required references uses native full reads. In-project mandatory content must actually be returned completely. Native MCP, editing and continuations retain host protocols; real equivalent CLI commands default to Context Mode. Do not add permissions, automatic indexing, remote fallback for impact analysis or graph algorithm changes.

Align existing discovery/body/UI/reference surfaces only. Collection membership and materialized sources remain unchanged unless their actual manifest contract requires it. Publish by an immutable source commit, validate the native manifest and let Lifecycle materialize it. No installed-copy edits.

Failure preserves the first actual error and scope. Source recovery uses new corrective commits; no force overwrite or fabricated receipts. Local completion requires all scope checks, native records/archive/journal and remote synchronization; root completion additionally requires official delivery, native materialization, real-host behavior, integration gates and no pending action.
