## 路由与协作复核

| 场景 | 预期路径及边界 |
| --- | --- |
| 读取源码、搜索路径、普通构建/测试 | FastCtx 原生文件、命令或 job 工具 |
| 修改源码、规则、方案或技术笔记正文 | 写作 Skill 指导表达；文件用 apply_patch，思源内容用其原生保存接口 |
| Trellis 绑定、阶段、Channel 与等待 | 原生 Trellis / 宿主命令；不包装为 FastCtx job |
| 外部资料、Codex 官方资料、代码语义检索 | 各检索工具规定入口；FastCtx 只分析完成后的普通结果文件 |
| 工具已暴露但报参数、权限、传输或服务错误 | 保留实际类别，不改称缺失或用其他工具模拟 |
| 继续、压缩恢复和未完成工具续接 | 复用断点，只补缺失或冲突事实及必要接口检查 |
| 决策证据未完成 | 保存决策节点与返回动作，再进行有界取证；不因暂无问题直接封口 |
| 实质新用户选择或已授权低风险增量 | 前者暂停依赖动作并原生重新规划；后者按当前任务合同继续，不重复批准 |
| 中文 Trellis 资产或思源知识写作 | 按内容加载参考；写作不授予状态切换或知识保存权限，无自动捕获 |

上述为接口和文档的人工语义复核，不是新会话模型行为评测。未派付费节点、未写思源测试知识、未改检索或 Trellis 运行时协议，也未处理 tmux 漂移。
